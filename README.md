# Pick It Up

This project is a class project for Object Oriented Programming, Spring 2025.
Pick It Up is a productivity app which includes note taking, AI chatting, a to-do list,
a calendar, and clock/timer features. SQLite is used to setup a local database and text
options under the Font menu can be used to set font size, color, font, and background color.

This project begin in development in January 2025, and concluded with the
project presentation and demo on 04/23/2025.

To Run:
- Java must be installed on the current device
- A Windows OS is required
- unzip the .zip file to a location of your choice
- Navigate to the target folder then run Pick It Up.jar
